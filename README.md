体育館のベンチや観客席から、**タブレット（iPad等）片手に試合を観ながら指先だけでリアルタイム記録・分析**ができるハンドボール専用スタッツWebアプリケーションです。

コートエリア9分割＋7mスローの直感配置、ベンチ選手交代機能、3大KPI（決定率・ターンオーバー率・GK阻止率）およびポゼッション分析（攻撃効率：OE）の即時自動算出に対応しています。

---

## 🌟 主な機能と特徴

### 1. タブレット横画面に最適化された「動画レス 2ペインUI」
- 画面左側で**「エリア選択 ➔ 選手選択 ➔ 結果タップ」**の最短動線を実現。
- 画面右側で**「リアルタイム3大KPI・個人成績・ログ一覧・ベンチ交代」**を即座に確認可能。
- 外部ライブラリ非依存の軽量設計により、通信環境の不安定な体育館でも**完全オフライン**で快適に動作。

### 2. コートエリア 9分割 ＋ 7mスロー配置
現代ハンドボールの戦術分析に則したエリア区分をコート図上に配置。
- **近距離層（6mライン近辺）**:
  - `① 左サイド` / `② カットイン・PV` / `③ 右サイド`
- **ミドル層（9mライン近辺）**:
  - `④ 左側ミドル` / `⑤ 中央ミドル` / `⑥ 右側ミドル`
- **ロング層（9mライン外・遠距離）**:
  - `⑦ 左側ロング` / `⑧ 中央ロング` / `⑨ 右側ロング`
- **特殊エリア**:
  - `⑩ 7mスロー`（ゴール直下中央に配置）
  - `⚡ 速攻 (FB)`

### 3. ハンドボール3大KPI ＆ ポゼッション効率（OE）の自動算出
シュートやミスの記録と同時に、試合の勝敗を左右する重要指標をリアルタイム集計します。
- **シュート決定率 (SH%)**: \\(\frac{\text{得点}}{\text{試投}} \times 100\\)
- **ターンオーバー率 (TO%)**: \\(\frac{\text{ターンオーバー数}}{\text{総攻撃回数(Poss)}} \times 100\\)
- **ゴールキーパー阻止率 (GK Save%)**: \\(\frac{\text{セーブ数}}{\text{枠内被シュート数}} \times 100\\)
- **攻撃効率 (OE)**: \\(\frac{\text{得点}}{\text{総攻撃回数(Poss)}} \times 100\\)

### 4. 試合タイマー連動 ＆ リアルタイム交代管理
- **タイマー機能**: 前半／後半の切り替え、カウントアップタイマーと連動し、各イベント発生時の試合時間（例: 前半 12:45）を自動タイムスタンプ化。
- **ワンタップ選手交代**: コート上のスタメン7名（GK含む）とベンチ控え選手を2ステップで即座に入れ替え可能。

### 5. データ保護 ＆ CSV出力
- **ローカル自動保存 (LocalStorage)**: アプリを誤って閉じたりリロードしても記録データを自動保持。
- **Excel対応CSVエクスポート**: ワンクリックでBOM付きUTF-8形式のCSVを出力（文字化けせずにExcelやスプレッドシートで分析可能）。
